1. Agent Identity

Agent Name: JobMate AI — Your Personal Placement Strategist

Agent Role: JobMate AI is an AI-powered placement preparation assistant developed to help college students prepare systematically for internships and campus placements. It analyses a student's resume alongside a target job description, identifies relevant skills and potential skill gaps, and provides AI-generated preparation guidance. The application also includes interactive SQL learning missions, target-role-specific quizzes, instant answer explanations, and a continuous learning progress tracker.

2. Agent Goal

The primary goal of JobMate AI is to help students prepare for technical placements through a personalized, realistic, and structured learning process. It aims to empower students to:

  • Understand the specific competencies required by a target job role.
  • Objectively recognize technical skill gaps existing in their current resumes.
  • Practise foundational database and role-based concepts via progressive quizzes.
  • Track preparation trajectory and performance metrics over time.

3. Special Feature: The Resume-to-Readiness Learning Loop

The Resume-to-Readiness Learning Loop:
Instead of stopping after passively analyzing a resume, JobMate AI connects resume analysis with active preparation guidance and technical practice. Students identify their skill gaps, receive a day-by-day preparation schedule from a local LLM, complete targeted quizzes, review explanations, and track their scores in SQLite.

4. Main Capabilities

  1. Resume & Job Requirement Analysis: Extracts text from PDF resumes using PyMuPDF and computes word-boundary matched skill overlaps against job requirements.
  2. Personalized Preparation Planning: Uses the local Qwen2.5:3B model through Ollama to generate an exact day-by-day study schedule based on available time.
  3. Interactive Technical Learning: Offers 3 tiers of SQL quizzes (Basics, Aggregation, Joins & Subqueries) with an 80% passing threshold, plus domain quizzes (Data Analyst, Software Engineer, Data Scientist, Web Developer).
  4. Quiz Evaluation & Progress Tracking: Evaluates answers in real time, provides detailed explanations, suggests next steps, and records every attempt into SQLite.

5. System Workflow

[1. User Input] Student specifies role, days (e.g. 7), uploads resume & enters JD. ↓ [2. Document Processing] PyMuPDF extracts selectable text stream directly in-memory. ↓ [3. Skill Analysis] Boundary-aware Regex identifies matched skills and skill gaps. ↓ [4. AI Guidance] Ollama (Qwen2.5:3B) generates structured, day-by-day learning tasks. ↓ [5. Technical Practice] Candidate solves 5-question SQL and Role-specific quizzes. ↓ [6. Progress Tracking] Scores, comparisons, and timestamps permanently stored in SQLite.

8. Working Prototype

JobMate AI is fully implemented as a local Streamlit web application running directly on the computer. Verified working modules include:

  • Seamless PDF resume upload with in-memory parsing.
  • Resume-to-job skill matching and gap calculation engine.
  • Local AI-generated study guidance via Ollama REST API.
  • Three sequential SQL quiz levels with unlock thresholds.
  • Target-role-specific quizzes with instant scoring and explanations.
  • SQLite-based quiz history tracking table with attempt metrics.

9. Limitations

  • PDF Format Dependency: Text extraction works on selectable text; image-based scanned PDFs require optical character recognition (OCR).
  • Catalog Scope: Skill detection is based on predefined technical keywords; implicit or non-standard synonyms may be omitted.
  • Model Hallucinations: AI-generated plans should be reviewed by students for optimal pacing.
  • Assessment Depth: Quizzes benchmark foundational concepts rather than comprehensive placement interviews.
  • Environment Prerequisites: Requires Python 3.13, local packages, and the Ollama model installed on the host machine.
  • Non-standard Score: The skill match percentage is an internal indicator, not an official hiring employability index.
